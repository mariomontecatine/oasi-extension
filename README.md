# Bloqueador de webs

Extensión de Chrome para bloquear las webs que elijas en las horas y días que quieras.

- Varias listas, cada una con su nombre (p. ej. «Ajedrez», «Redes sociales»).
- Webs como `chess.com` (incluye subdominios) o `youtube.com/shorts` (solo esa sección).
- Días con un clic (L M X J V S D) o atajos: todos, lunes a viernes, fin de semana.
- Franjas horarias «De 16:00 a 21:00», o «Todo el día». Una franja como 23:00–01:00 cruza la medianoche.
- Los cambios se guardan solos.

## Instalar

1. Abre `chrome://extensions`.
2. Activa **Modo de desarrollador** (arriba a la derecha).
3. Pulsa **Cargar descomprimida** y elige esta carpeta.

En WSL, la carpeta está en `\\wsl$\<distro>\home\mario\repos\oasi-extension`.
